# Contributing to AgriShield AI

Thank you for your interest in contributing to **AgriShield AI**! We welcome contributions from developers, agronomists, data scientists, and Web3 builders.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
- Search existing issues to ensure the bug hasn't been reported.
- Create a new issue describing the bug, steps to reproduce, expected vs actual behavior, and environment details.

### 2. Suggesting Enhancements
- Open an issue with the tag `enhancement`.
- Clearly explain the problem the enhancement solves and proposed implementation ideas.

### 3. Submitting Pull Requests (PR)
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/Agri-Shield-AI.git
   cd Agri-Shield-AI
   ```
3. **Create a new branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Set up virtual environment & install dependencies**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
5. **Make your changes** following clean coding standards:
   - Use PEP 8 formatting for Python code.
   - Ensure all secrets are kept in `.env` and never committed.
   - Verify all routes and endpoints function without errors.
6. **Commit and Push**:
   ```bash
   git commit -m "feat: Add new awesome capability"
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request** against the `main` branch with a clear description of your changes.

---

## 📜 Code of Conduct
Please be respectful, collaborative, and constructive when engaging with our community.
